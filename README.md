## Run Locally

Just open `index.html` directly in a browser, or serve it locally:

```bash
npx serve .
```

Then visit `http://localhost:3000`.

## Deployment

This is a static site with zero build steps. It can be deployed on any static hosting platform:

- **Vercel** — Import the repo, set Framework Preset to "Other", deploy
- **Netlify** — Drag-and-drop the folder at [netlify.com/drop](https://app.netlify.com/drop), or connect via GitHub
- **Render** — Create a Static Site, leave Build Command empty, set Publish Directory to `.`
- **GitHub Pages** — Enable Pages in repo Settings → source: `main` branch, root
